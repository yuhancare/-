✏️ 화면 제목/텍스트 관리
대시보드 곳곳의 주요 제목·메뉴명·카드 제목을 직접 수정할 수 있어요.
이모지(아이콘)도 함께 입력하면 그대로 표시돼요. 비워두면 자동으로 기본값으로 복원돼요.
🧩 대시보드 위젯 관리
대시보드 탭에서 관리자 모드 켜면 각 위젯에 ↑↓ 이동 / 숨기기 버튼이 생겨요.
숨긴 위젯은 여기서 한 번에 복원할 수 있어요.
🔑 관리자 비밀번호 변경
현재 비밀번호 확인 후 새 비밀번호로 변경할 수 있어요.
🏷 도서 카테고리 관리
도서 등록 시 사용할 카테고리(구분)를 추가/삭제할 수 있어요. 기본 카테고리는 삭제할 수 없어요.
📌 도서 신청 안내문구 수정
도서 신청 페이지 상단에 표시되는 안내문구를 수정할 수 있어요. (줄바꿈은 그대로 반영돼요)
💾 데이터 백업
현재 도서/대여/신청/북크닉 데이터를 엑셀 파일로 다운로드해요. 정기적으로 백업해두면 안전해요.
🔄 구글시트 동기화 상태
대시보드는 5초마다 구글시트와 자동 동기화돼요.
